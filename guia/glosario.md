# Glosario

Palabras que vas a oír todos los días. No hay que memorizarlas: cuando la IA diga una, vuelve aquí.

| Palabra              | Qué es                                                                                                    |
| -------------------- | --------------------------------------------------------------------------------------------------------- |
| Repo                 | El proyecto completo con su historial. Vive en tu compu y, como copia remota, en GitHub.                  |
| Commit               | Una foto del proyecto con nombre y fecha. Un punto al que puedes volver.                                  |
| Rama (branch)        | Una línea de trabajo paralela para un cambio, sin tocar lo que ya funciona (`main`).                     |
| Pull request (PR)    | "Revisa mi cambio antes de integrarlo". Muestra el diff, permite comentar y correr pruebas.             |
| Merge                | Integrar una rama en otra. Normalmente tu cambio a la principal.                                         |
| Diff                 | La lista exacta de líneas que cambian entre dos versiones.                                                |
| Bug                  | Un comportamiento distinto al esperado. Se reproduce, se entiende la causa, se arregla, se prueba.       |
| Localhost            | Tu app corriendo en tu propia máquina. Nadie más la ve hasta que la publicas.                            |
| Prompt               | Lo que le pides a la IA: contexto + objetivo + restricciones. En español está bien.                       |
| Frontend             | Lo que el usuario ve y toca. Corre en su navegador.                                                       |
| Backend              | Lo invisible: lógica, permisos y acceso a datos. Corre en una máquina que tú controlas.                   |
| Base de datos        | El almacén persistente de la información. Solo el backend le habla.                                       |
| API                  | El contrato que define cómo otro código puede pedirle cosas a un sistema. El menú.                        |
| Endpoint             | Una URL concreta que responde a una petición. Un platillo del menú.                                       |
| API key              | Tu llave secreta para usar un servicio. Nunca en el código, nunca en un chat.                             |
| Variable de entorno  | Un valor que vive fuera del código (en `.env` o en el hosting). Ahí van las llaves.                       |
| Dependencia          | Código de otros que tu proyecto usa (una librería). Se lista en `package.json`.                           |
| Librería             | Colección de funciones que tu código llama cuando quiere.                                                 |
| Framework            | Estructura que llama a tu código y decide el flujo (Next.js, Astro).                                      |
| Stack                | El conjunto de herramientas con que se construye y despliega tu app.                                      |
| Conector / MCP       | El enchufe que le da a la IA acceso a una herramienta (Slack, Gmail, tu base). MCP es el estándar.        |
| Skill                | Una guía paso a paso que la IA sigue cuando le pides algo. Un archivo `SKILL.md`.                         |
| Build                | Compilar el proyecto a los archivos que se sirven en internet.                                            |
| Deploy / desplegar   | Publicar una build en internet con una URL.                                                               |
| Preview              | Un deploy de prueba, con URL propia, que solo ve tu equipo.                                               |
| Producción           | El deploy que ve todo el mundo. Un error aquí lo ven todos.                                               |
| Rollback             | Volver a un deploy anterior cuando producción falla.                                                      |
| Token                | Trozo de palabra con el que la IA cuenta el texto. Unos 4 caracteres.                                     |
| Ventana de contexto  | Cuánto texto puede "ver" la IA a la vez. Lo que no cabe, para ella no existe.                             |
| Alucinación          | Cuando la IA dice algo plausible pero falso, con seguridad. Se verifica contra la fuente oficial.         |
| Agéntico             | Cuando la IA no solo responde: ejecuta herramientas (lee, edita, corre comandos) hasta lograr el objetivo. |
