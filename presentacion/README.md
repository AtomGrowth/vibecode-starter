# La presentación

`vibecode-para-no-tecnicos.html` es la clase completa (36 diapositivas) en un solo archivo. No
necesita internet salvo para cargar las tipografías.

## Cómo verla

Haz doble clic en `vibecode-para-no-tecnicos.html` y se abre en tu navegador.

Controles:

- **Flechas ← →** (o barra espaciadora): avanzar y retroceder.
- **N**: mostrar u ocultar las notas del presentador (el guion de quien da la clase).
- **F**: pantalla completa.
- **Inicio / Fin**: primera y última diapositiva.

## Qué contiene

Cinco partes: el criterio primero, fundamentos sin miedo, operar con criterio, tu primer vibecode
en vivo, y no romper nada. Cada diapositiva de fundamentos trae definición precisa, analogía y
hechos; las notas del presentador llevan el guion con fuentes.

## El original editable

Este HTML es una copia para ver y compartir. El original editable es un deck de Claude (Slides), que
se puede exportar a PDF o PowerPoint desde ahí. Si hay que cambiar contenido, se edita el deck y se
regenera este archivo; no se edita el HTML a mano.
